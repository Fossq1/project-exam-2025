Athlete API

This API handles athletes in the Sportsworld application.
The API supports retrieving, creating updating and deleting athletes.

Base URL

http://localhost:5177/athlete

Athlete Model

                   
                       {
                           "id": number,
                           "name": string,
                           "gender": string,
                           "price": number,
                           "image": string,
                           "purchaseStatus": boolean 
                         }

GET /athlete

Returns a list of all athletes

Request

No Parameters required.

Response (200 OK)

                   
                       [{
                           "id": 1,
                           "name": "Jon Jones",
                           "gender": "Male",
                           "price": 5000,
                           "image": "images/athletes/Jones2.png",
                           "purchaseStatus": false
                       }]

Error response

  • 500 - Interntal Server Error

GET /athlete/{id}

Return a single athlete by ID

Path parameter

id - Athlete ID

Response (200 OK)

                   
                       {
                           "id": 1,
                           "name": "Jon Jones",
                           "gender": "Male",
                           "price": 5000,
                           "image": "images/athletes/Jones2.png",
                           "purchaseStatus": false
                       }

Error responses

  • 404 - Athlete not found
  • 500 - Internal Server Error

POST /athlete

Creates a new athlete

Request body

                   
                       {
                           "name": "Alex Pereira",
                           "gender": "Male",
                           "price": 4500,
                           "image": "images/athletes/Pereira.png",
                           "purchaseStatus": false
                       }

Error responses

  • 400 - Bad Request
  • 500 - Internal Server Error

PUT /athlete

Updates an existing athlete. Use when editing an athlete or when an athlete is purchased.

Request body

                   
                       {
                           "id": 1,
                           "name": "Jon Jones",
                           "gender": "Male",
                           "price": 5000,
                           "image": "images/athletes/Jones2.png",
                           "purchaseStatus": false
                       }

Response

  • 204 - No Content (success)

Error responses

  • 400 - Bad Request
  • 500 - Internal Servier Error

DELETE /athlete(id)

Removes athlete from the database using provided athlete ID.

Path parameter

  • id - Athlete ID(number)

Example request

                   
                       DELETE http://localhost:5177/athlete/3

Response

  • 204 - No Content (deleted successfully)

Error responses

  • 404 - Could not find athlete to delete
  • 500 - Internal Server error

HTTP Status Codes For Athlete API

  • 200 - OK
  • 201 - Created
  • 204 - No Content
  • 400 - Bad Request
  • 404 - Not Found
  • 500 - Internal Server Error

Finance API

This API updates data such as budget and purchase values

Base URL

http://localhost:5177/finance

Finance Model

                   
                       "id": number,
                       "moneyLeft": number,
                       "moneySpent": number,
                       "numberOfPurchases": number

Get /finance

Returns a list of all finance records.

Response (200 OK)

                   
                       [
                           {
                               "id": 1,
                               "moneyLeft": 25000,
                               "moneySpent": 5000,
                               "numberOfPurchases": 2
                           }
                       ]

Error Responses

  • 404 - Server side exception
  • 500 - Database side exception

GET /finance/{id}

Returns finance data for the specific ID.

Path parameter

  • id - Finance ID (number)

Response (200 OK)

                   
                       {
                           "id": 1,
                           "moneyLeft": 25000,
                           "moneySpent": 5000,
                           "numberOfPurchases": 2
                       }

Error Responses

  • 404 - Finance record not found
  • 500 - Database or server exception

PUT /finance

Updates financial data such as moneyLeft, moneySpent and numberOfPurchases.

Request body

                   
                       "id": 1,
                       "moneyLeft": 25000,
                       "moneySpent": 5000,
                       "numberOfPurchases": 2

Response

  • 204 - No Content (update successful)

Error Response

  • 500 - Database or server exception

POST /finance

Creates an new finance entry

Request body

                   
                       {
                           "moneyLeft": 20000000,
                           "moneySpent": 3000,
                           "numberOfPurchases": 2
                       }

Response

  • 201 - Created

Error responses

  • 500 - Database or server error

DELETE /finance?id={id}

Deletes the finance record with the specified ID.

Path parameter

  • id - Finance ID (number)

Response

  • 204 - No Content (deleted successfully)

Error responses

  • 404 - Finance record not found
  • 500 - Server exception

HTTP Status Code (FinanceAPI)

  • 200 - OK
  • 201 - Created
  • 204 - No Content
  • 404 - Not Found
  • 500 - Internal Server Error

NOTE: Not all the endpoints return all status codes. Responses depends on controller logic and database state.

POST /imageupload

Uploads an image file and saves it to a category folder under wwwroot/images.

Descrption

Uploads an image to a category folder. If the folder does not exist, it will be created automatically. The API saves the image with a unique filename and returns the relative path to the file.

Request

The request must be sent as: multipart/form-data.

Example request

               
                   POST http://localhost:5177/imageupload
                   Content-Type: multipart/form-data


                   file: athlete1.png
                   category: athletes

Successful Response (201 Created)

API return an object containing the stored image path.

               
                   {
                       "path": "images/athletes/2f0c2c7a-7d16-4d0a-9dbf-6a4f5b2db1a3.png"
                   }

Error responses

  • 400 - Bad Request (No file uploaded)
  • 500 - Internal Server Error (Something went wrong with the POST-request)

Notes

  • Each uploaded file is given a unique filename to prevent files from overwriting each other.
  • Images are stored in /images{category}/ and can be accessed directly by the application.
  • The returned file path can be saved in the database and later used by the frontend to display the image.

Venue API

Venue API is used to manage venues in the Sportsworld application. It allows the users to retrieve, create, update and delete venues.

Venue API Base URL

http://localhost:5177/venue

Venue Model

                   
                       {
                           "id": number,
                           "name": string,
                           "location": string,
                           "capacity": number
                       }

GET /venue

Returns a list of all venues.

Response (200 OK)

                   
                       [
                           {
                               "id": 1,
                               "name": "Madison Square Garden",
                               "location": "New York",
                               "capacity": 20000
                           }
                       ]

Error Responses

  • 500 - Database or server exception

GET /venue{id}

Returns a single venue by its ID.

Path parameter

  • id - Venue ID (number)

Response (200 OK)

                   
                       {
                           "id": 1,
                           "name": "Madison Square Garden",
                           "location": "New York",
                           "capacity": 20000
                       }

Error Responses

  • 404 - Could not find a venue with that ID
  • Internal server error

POST /venue

Creates a new venue

Request body

                   
                       {
                           "name": "T-Mobile Arena",
                           "location": "Las Vegas",
                           "capacity": 18000
                       }

Response (201 Created)

                   
                       {
                           "id": 3,
                           "name": "T-Mobile Arena",
                           "location": "Las Vegas",
                           "capacity": 23000
                       }

Error Responses

  • 500 - Internal server error

PUT /venue/{id}

Updates an existing venue by ID.

Path parameter

  • id - Venue ID

Request body

                   
                       {
                           "id": 3,
                           "name": "T-Mobile Arena",
                           "location": "Las Vegas",
                           "capacity": 23000
                       }

Response

  • 204 - No Content (updated successful)

Error responses

  • 400 - Id mismatch
  • 500 - Internal server error

DELETE /venue{id}

Deletes a venue by ID.

Path parameter

  • id - Venue ID (number)

Response

  • 204 - No Content (deleted succesfully)

Error Responses

  • 404 - Venue not found
  • 500 - Internal server error
